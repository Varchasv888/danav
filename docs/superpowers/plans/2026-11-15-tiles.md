1. Add tiles business onboarding option and default, preserving existing tenant industries.
2. Add nullable brand and finish columns with migration 0149; reuse size for tile dimensions.
3. Expose product metadata through item create/edit and imports. Default new goods to BOX; preserve existing units.

5. Verify parsing of the supplied inventory, importer stock posting, TypeScript checks, and existing business-rule tests.
